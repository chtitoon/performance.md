# performance.md

A plain-text format for performance budgets and SLOs, and a small CLI that checks and compares against it. The counterpart of [DESIGN.md](https://github.com/google-labs-code/design.md) for speed: a `PERFORMANCE.md` file holds the rules in its YAML front matter and the reasons in its prose.

Status: alpha. The format is in [spec.md](spec.md); the CLI comes next.
